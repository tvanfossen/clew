# clew

> *A **clew** is the ball of thread Ariadne gave Theseus to find his way out of the labyrinth —
> the archaic spelling, and the direct ancestor, of the word "clue".*

**A symbol graph of your repository, served to Claude over MCP.** One lookup returns a function's
body with its callers, its callees, the thread it runs on and the locks it takes — instead of a
chain of greps the agent rebuilds every session and loses at every context compaction.

## What you get

- **One call instead of a search chain.** `dossier` answers "who calls this, and what does it
  touch" in a single reply, including relationships grep cannot see: function-pointer callbacks,
  thread entry points, the locks held around a call.
- **Answers that say what they do not know.** An unresolved call, a layer that failed to build,
  or a file clew cannot parse is reported as *unresolved* — never quietly as "none".
- **An index that keeps itself current.** Touched repositories are refreshed every 15 s, a query
  against a stale index refreshes it before answering, and only edited files are re-parsed.
  Separate git worktrees get separate indexes.
- **Measured, not asserted.** Each release is graded against the same agent working without
  clew, and published with the defects that move its numbers:
  [acceptance results](https://github.com/tvanfossen/clew/tree/main/acceptance/runs).

## Quick start

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh   # the plugin launches clew through uv
sudo apt install doxygen       # only for C and C++ (brew install doxygen on macOS)
```

Then, in Claude Code:

```
/plugin marketplace add tvanfossen/clew
/plugin install clew@clew
```

The plugin runs the clew-trace release it was published with, through `uvx`; the first launch
installs it. To register clew without the plugin, see
[Install](https://github.com/tvanfossen/clew/blob/main/docs/OVERVIEW.md#install).

Ask Claude to index the repository — it calls `index(action='refresh')` — then ask about your
code. Rust repositories also need `cargo +nightly`.

**What the plugin runs, sends and fetches.** An MCP server (`clew-mcp`) that builds and queries a
local SQLite index under `~/.local/state/clew`, and one `PostToolUse` hook (`clew-hook`) that, after
a file read or search, adds a short note naming the index call that would have answered more;
`CLEW_HOOK_DISABLE=1` turns it off. Its first launch fetches the pinned clew-trace release from
PyPI through `uv`; after that, clew itself sends nothing over the network. Building an index
runs the repository's own tooling — doxygen on C/C++, and `cargo` on Rust, which can download the
crate's dependencies — so treat indexing a tree like building it. See
[SECURITY.md](https://github.com/tvanfossen/clew/blob/main/docs/SECURITY.md).
